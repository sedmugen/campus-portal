# Security Policy: Campus Portal

| Version | Supported          |
| :--- | :--- |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The security and privacy of users and contributors to **Campus Portal** are taken seriously.

If you discover a security vulnerability or sensitive information exposure:

1. **Do not create a public GitHub issue.**
2. Email a detailed report directly to **Saad** via GitHub security advisories or via your registered contact email for `sedmugen`.
3. Include the following details in your report:
   - Description of the vulnerability.
   - Steps to reproduce or proof-of-concept payload.
   - Potential impact of exploitation.
   - Any suggested mitigations or patches.

### Response Timeline
- **Initial Response**: Within 48 hours acknowledging receipt of the report.
- **Status Update & Assessment**: Within 5 business days with triage and severity scoring.
- **Fix & Disclosure**: Coordinated public release after patch verification.
